# Paleta de Blapos

La fuente de color es [Shared/tokens.css](../../../resources/css/Shared/tokens.css). Elige el token según lo que comunica la interfaz.

| Función | Tokens |
| --- | --- |
| Marca, foco y selección | `--fg-primary`, `--fg-primary-hover`, `--fg-primary-soft` |
| Texto, títulos y contexto | `--fg-text`, `--fg-heading`, `--fg-muted` |
| Área de trabajo y superficies | `--fg-canvas`, `--fg-surface`, `--fg-table-head` |
| Bordes y foco | `--fg-border`, `--fg-control-border`, `--fg-focus` |
| Éxito, advertencia, peligro e información | `--fg-success`, `--fg-warning`, `--fg-danger`, `--fg-info` y sus variantes suaves |

Reutiliza badges y mensajes de estado para comunicar el resultado con texto. Verifica contraste con la superficie efectiva, también durante foco, hover y selección.
